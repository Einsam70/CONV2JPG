A simple, offline website for converting PNG files with metadata into smaller JPG files and extracting the metadata to an associated TXT file.

A ZIP export function is included for large volumes of images. If you choose not to export as a ZIP file, the system will require you to confirm the names of the images and associated files individually.

Español

Una simple página que funciona offline para convertir archivos PNG con metadatos en archivos JPG con menos peso y extracción de metadatos a fichero TXT asociado.

Función exportación en ZIP incluida para volúmenes grandes de imágenes. En caso de no exportar en ZIP el sistema requerirá confirmación de los nombres de las imágenes y ficheros asociados de forma individual.
